# 06 · AI for Research

把 AI 作为科研工具，而不是事实来源。

## 计划内容

- [ ] ChatGPT / Codex / Claude Code 的分工
- [ ] AI 辅助写代码
- [ ] AI 辅助 Debug
- [ ] AI 读陌生代码仓库
- [ ] AI 辅助读论文
- [ ] AI 辅助文献检索
- [ ] AI 辅助实验设计
- [ ] AI 辅助结果整理
- [ ] AI 辅助写作
- [ ] 幻觉与验证
- [ ] 如何建立 evidence chain

## 推荐原则

```text
人：问题定义 / 判断 / 研究决策
AI：检索 / 阅读 / 编码 / 分析辅助
证据：论文 / 代码 / 日志 / 实验结果
```

AI 输出可以作为候选答案，但关键科研事实必须回到可验证证据。
