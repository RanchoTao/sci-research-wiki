# 假设、基线与消融

## 一个 idea 应该能够失败

“新方法可能更好”不是充分的研究设计；**更好在哪里、相对谁、在什么预算和数据上、什么结果会否定它**，需要事先规定。

## 最小研究设计

| 元素 | 合成回归示例 |
| --- | --- |
| 主要假设 | 使用两个有效特征的模型有更低测试 MSE |
| 基线 | 训练集均值预测 |
| 对照 | 去掉第二特征但保留其余训练程序 |
| 主要指标 | 固定种子的独立测试集均方误差（越低越好） |
| 记录单位 | 每个随机种子一行 |
| 失败条件 | full 误差没有稳定低于去掉第二特征的对照 |
| 局限 | 因为生成机制已设定，无法外推真实任务 |

## 常见混淆

- **改变多个条件**：同时改训练步数、数据划分和模型大小，无法归因。
- **指标后选**：看见哪个指标好再把它设为主要指标。
- **统计不确定性被忽略**：几次随机种子不是“显著改善”的充分证据；若要给正式置信区间，需要说明抽样对象、独立性和估计方法。
- **把没有证据当作无效**：未发现增益不等于证明效应为零。
- **新颖性与正确性混淆**：实验成立不证明结论独创；必须独立检索先行工作与已发表版本。

## 保存一份预注册式简表

在跑实验前，把主要假设、比较对象、指标、数据划分、预算、停止条件写入版本控制。探索性分析可以继续，但报告中要与预定分析明确分开。
