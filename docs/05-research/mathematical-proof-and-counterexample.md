# 数学命题、证明与精确反例

## 数学科研与实验科研的验收有什么不同

**一个精确反例**足以推翻全称命题；但跑过上万个数值实例仍不能证明全称命题成立。数学研究首先要检查对象、量词、假设、结论与推导是否匹配。

## 教学命题：矩阵的平方能否直接展开？

考虑实数域上的任意两个同阶方阵 A、B。有人将数的恒等式直接套到矩阵上：

```text
错误的全称主张：
对任意 A、B，(A+B)^2 = A^2 + 2AB + B^2
```

不成立的原因是矩阵乘法一般不交换。真实恒等式为：

```text
(A+B)^2 = A^2 + AB + BA + B^2
```

要推翻错误的全称命题，只需找到一个确切的 A、B 使左右不等。

## 一个完全精确的反例

取

```text
A = [0 1]   B = [0 0]
    [0 0]       [1 0]
```

直接计算得：

```text
AB = [1 0]   BA = [0 0]   (A+B)^2 = [1 0]
     [0 0]        [0 1]             [0 1]

A^2 + 2AB + B^2 = [2 0]
                   [0 0]
```

左右不同，故原**全称命题被反例否定**。这里使用整数精确运算，不存在浮点容差问题。

## 纠正后的命题及其证明

如果额外假设 `AB = BA`，那么由分配律

```text
(A+B)^2 = A^2 + AB + BA + B^2
        = A^2 + 2AB + B^2
```

从而恒等式成立。反之，如两边相等，将公共的 `A^2`、`B^2` 消去可得 `AB+BA=2AB`，即 `BA=AB`。因此对于实方阵，这个式子成立**当且仅当** A、B 可交换。

代码验证只能检查给定实例；上面的一般性结论依赖符号代数证明，而不是枚举。学习时要分别保存推导和程序回执。

## 更接近真实数学科研时还要做什么

- 检查论文原始版本、勘误和正式出版版本，避免针对旧错误重复发现。
- 记录精确的假设、量词、结论和证明义务。
- 用 Lean 或符号系统辅助检查时，明确它实际证明的命题与范围。
- 区分：内部候选、已验证局部事实、严格一般证明、原创性核验。
