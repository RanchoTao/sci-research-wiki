# 从论文到证据卡

## 问题：读过不等于用得上

很多检索卡片只记录标题和摘要，却不能回答“这个方法到底在什么假设下有效”“结论在哪一页”。一张证据卡应该能支持未来对原文的独立检查。

## 六个阅读动作

1. **确认身份**：标题、作者、年份、DOI/arXiv 编号和具体版本；预印本与期刊版可能不同。
2. **定位问题**：论文解决什么问题，研究对象是什么。
3. **核对条件**：明确输入、数据假设、边界条件、评价协议；不只抄结论。
4. **记录主张**：找到摘要之外真正支持该结论的定义、定理、表、图或实验段落。
5. **验证证据**：有无代码/数据、是否属于作者自行报告、是否有重复实验或外部复核。
6. **写下限制**：论文没有证明或测试的场景、可能的替代解释、与自己问题的距离。

## 证据卡模板

```text
引用键和精确版本：
原始来源 URL / DOI：
研究问题：
核心主张（自己的转述）：
适用条件与假设：
原文定位（页/定理/图/表）：
方法或数据：
证据种类（理论证明/仿真/真实数据/主观判断）：
我是否独立核验：未核验 / 部分 / 完成
与当前课题的关系：
下一次要检查什么：
```

阅读 AI 生成的论文摘要时，**逐项核对原始文档**，尤其是定理版本、数值结论及引用是否真实存在。

## 最小练习

挑一篇自己要复现的论文，制作 1 张证据卡；找到一条作者明确写出的局限，区分“作者承认的限制”和“你推测的限制”。
