# 第一次科研循环

## 你为什么需要学这个

初次进实验室容易把“跑通别人代码”“看了多少论文”和“真正验证了一个问题”混为一谈。科研循环的最小单位不是模型，也不是论文，而是一个 **可检验的主张**。

## 一个足够小的研究问题

可以从这样的教学问题开始：在合成线性数据里，加入第二个有效特征，是否比只用第一个特征的模型具有更低的样本外 MSE？

它有明确对照，也可能被结果否定。这里的数据生成机制人为设定，结果只是训练研究工作流，**不能宣称新发现**。

## 最小可用流程

1. **问题**：写出主要主张和适用范围；例如“在预先固定的数据生成机制上，双特征模型样本外误差更低”。
2. **文献/背景**：找出线性回归、训练/测试数据隔离等基本定义；记录原始来源和版本。
3. **基线**：先做训练集均值预测，再做单特征模型。
4. **实验**：固定数据生成代码、训练样本数、测试样本数、种子列表和指标。
5. **对照**：改变一个条件（去掉第二特征），其余保持一致。
6. **记录**：保存每个种子的指标、脚本版本、运行命令和环境。
7. **解释**：区别“在这几个固定种子上有效”和“普遍有效”。
8. **交流**：提交原始表格、汇总与下一轮实验计划。

## 一页开题卡

```text
问题：
研究对象与假设：
现有基线：
主要指标（方向）：
固定的控制变量：
会使假设被否定的结果：
需要保存的原始证据：
本轮的停止/完成条件：
```
