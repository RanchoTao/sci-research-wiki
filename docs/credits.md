# 参考项目与资料来源

本项目是独立编写的科研工作流入门手册。下面项目提供 **信息架构与教学组织方式** 的参考，不等于内容移植，也不意味着它们对本站背书。

- [BIMSA MathAI Wiki](https://github.com/RanchoTao/BIMSA-MathAI)：参考 MkDocs Material、GitHub Pages、开放贡献和内容分级思路。
- [HackWay MIT CS 学习路线](https://hackway.org/docs/cs/path/mit/)：参考先修关系、课程目标和清晰的学习路径表达。
- [CS DIY Wiki](https://csdiy.wiki/)：参考按学习阶段组织工具、课程、实践项目与社区贡献。
- [本项目 GitHub 仓库](https://github.com/RanchoTao/sci-research-wiki)：Issue、版本历史、源文档和修订反馈。

各篇文章的“延伸阅读”单独列出对应原始软件/论文/教程。第三方资料版权归原作者所有；本站不复制无授权课程课件、论文 PDF 或整篇外部教程。

发现失效链接、技术事实错误或过时命令，请提交可复查的 Issue / Pull Request。
